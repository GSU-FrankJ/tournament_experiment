### 2.3 Network structure of the evaluated policy

Identical in the three arms:

| item | value (bw, jt, jt_es) | Src |
|---|---|---|
| hidden layers of the actor | 2 | [7,8] |
| width of each hidden layer | 64 | [6,8] |
| activation of the hidden layers | tanh | [6,7,8] |
| inputs of the actor | 2: tau_t = (t-1)/(T-1) and d/((t-1)B) (0 at stage 1) | [6,8] |
| outputs of the actor | 2 linear outputs (z_mu, z_c) | [7,8] |
| Beta mean parameter mu | clamp(sigmoid(z_mu), mu_clamp, 1 - mu_clamp) | [7] |
| mu_clamp | 1e-06 | [6] |
| Beta concentration c | c_min + softplus(z_c) | [7] |
| c_min | 100 | [6] |
| Beta parameters | alpha = mu c, beta = (1 - mu) c | [7] |
| action and effort | a ~ Beta(alpha, beta) clipped to [action_clamp, 1 - action_clamp]; e = e_min + a (e_max - e_min) | [6] |
| action_clamp | 1e-06 | [6] |
| e_min and e_max | 0; 100 | [6] |
| mean effort of the evaluated policy | e_hat = e_min + (e_max - e_min) alpha/(alpha+beta) in float64 from float32 alpha,beta | [6] |
| critic (training only) | separate network 2 -> 64 tanh -> 64 tanh -> 1, no shared trunk | [7,8] |

Different between the arms:

| item | bw | jt | jt_es | Src |
|---|---|---|---|---|
| do the stages share one network | no: one network per stage | yes: one network for all three stages (the stage enters through the input tau_t) | yes: one network for all three stages (the stage enters through the input tau_t) | [7,8] |
| distinct networks in the evaluated policy | 3 | 1 | 1 | [7,8] |
| how the stage networks arise | one actor/critic pair is trained through the phases of stages 3, 2, 1 without re-initialisation; a copy of the actor is frozen at the end of each phase (the code also freezes a copy at the end of the stage-1 phase, which the evaluated policy does not use); the evaluated policy takes stages 3 and 2 from the frozen copies and stage 1 from the live actor stored in state_end_stage1.pt (tools/t3/t3_eval.load_bw) | one actor/critic pair is trained on whole-game episodes; all stages are updated together in every update | one actor/critic pair is trained on whole-game episodes; all stages are updated together in every update | [7,8] |

| arm / phase | root starts (share) | stage 2 starts (share) | stage 3 starts (share) | updates | Src |
|---|---|---|---|---|---|
| bw, phase of stage 3 | 0 (0) | 0 (0) | 512 (1) | 1600 | [6,7] |

- bw: stage 1: root: d = 0 for every episode. Stages 2 and 3: bin-balanced: a bin of width es_bin_width (10) of D_t is chosen uniformly, then d is uniform in the bin; start_weights.scheme = bin_balanced. [6,7]
- jt: stage 1: root: d = 0 for every episode. Stages 2 and 3: no exploring starts (joint.starts.stage2 = joint.starts.stage3 = 0). [6,7]
  Episodes: whole-game episode from its start stage to stage 3; one policy row at every stage t >= start stage. [7]
- jt_es: stage 1: root: d = 0 for the root starts. Stages 2 and 3: bin-balanced exploring starts: a bin of width es_bin_width (10) of D_t is chosen uniformly, then d is uniform in the bin. [6,7]
  Episodes: whole-game episode from its start stage to stage 3; one policy row at every stage t >= start stage. [7]
