## 2. Training pipeline (D1)

**Reward.** `reward_mode = expected`. The terminal reward is the conditional expectation w_L + ΔW·F_ξ(d + e_own − e_opp) − k·e_own² (`run/v2_rollout.py`). All draws are still made.

**Phase A: stage 2 only, 1600 updates.**
- 512 episodes per update.
- Bin-balanced exploring starts on D₂ (bin width 10; 40 bins at q=50, 44 at q=60).
- All rows normalized; stochastic stage-2 actions.
- Lagged opponent refreshed every 20 global updates.
- LR (actor and critic): 3e−4 constant for local updates 1–1200, then linear 3e−4 → 3e−5 over local updates 1201–1600.

**Freeze.** At the end of A the actor is deep-copied as the frozen stage-2 snapshot (B2 machinery: no gradient, eval mode, in no optimizer).

**Phase B: stage 1 only, 600 updates.**
- 512 root episodes per update (t=1, d=0).
- `adv_norm_scope = stage1_rows`: the policy loss and the advantage normalization use stage-1 rows only.
- `continuation_action_mode = mean`: at stage 2 both players execute the frozen snapshot's Beta mean. The draws are made and discarded.
- Lagged stage-1 opponent refreshed every 20 global updates.
- LR (actor and critic): linear 3e−4 → 3e−5 over local updates 1–600.

**LR form.** lr(j) = start + (end − start)·(j − j₀)/(j₁ − j₀), from `run/run_final_dp_br_round3_dense.py:lr_at` (kind `linear`), applied through `run/run_v2_stagewise.py:Run.lr_for`. It is applied to both optimizers before each update, constant within the update, with the Adam state preserved. The end value 3e−5 is the existing G3/G4 linear end value (`MultiStage/Discussion/ROUND2_T2_FOUR_GROUP_SETTINGS_20260909.md`, lines 24 and 38).

**Not used.** Joint training, Phase C, tail averaging.

**Evaluated candidate.** The last iterate, as Beta means: stage 2 = the actor at the end of A (frozen), stage 1 = the actor at the end of B.

**Unchanged from the pilots.**
- RNG: numpy PCG64 streams seeded by SeedSequence([seed, q, namespace]), with namespaces init 0, env_noise 1, learner_action 2, opponent_action 3, starts_roles 4, minibatch 5.
- Samplers (numpy Beta; no inverse-CDF).
- On-path rule: |d − drift| < 2q (open interval), with exact cell masses.
- ẽ₁ residual-band method on the final tier.

**PPO and network** (`agents/ppo_curriculum.py`).

| Setting | Value |
|---|---|
| Actor | 2 → 64 tanh → 64 tanh → 2 |
| Critic | separate, 2 → 64 tanh → 64 tanh → 1 |
| Init | hidden layers orthogonal gain √2, bias 0; actor head zero; critic head orthogonal gain 1 |
| Beta | μ = clamp(sigmoid(z_μ), 1e−6, 1−1e−6), c = 100 + softplus(z_c), α = μc, β = (1−μ)c |
| Action clamp | 1e−6 |
| Adam | betas (0.9, 0.999), eps 1e−8, weight decay 0 |
| Clip | 0.2 |
| Value coefficient | 0.5 |
| Entropy coefficient | 0 |
| Grad-norm clip | 0.5 (separate per network) |
| Epochs / minibatch | 10 epochs, minibatch 256 |
| γ, λ | 1, 1 |
| Advantage normalization | eps 1e−8 |
| Precision / threads | float32 networks; CPU; 1 thread per process (torch, OMP, MKL, OpenBLAS) |

**Observation.** `encode_obs(t, d)` = [(t−1)/(T−1), d/((t−1)B)] in float32. Stage-1 inputs carry d = 0.

**Verifier cadence during training** (fixed budget, no early exit). The existing rules are recorded as "would have fired" only:
- warm-up at local update 100;
- stability checks every 20 (drift threshold 0.01, KL threshold 0.01, 2 consecutive);
- timeout 100 (A) and 25 (B);
- a call at phase end.

Weight exports every 25 global updates.

**Verifier tiers** (`utils/dp_br_verifier.py`).

| Tier | state step | effort step | GL nodes per half |
|---|---|---|---|
| development | 4 | 1 | 16 |
| final | 2 | 0.5 | 32 |

The recovery grid step is 0.5.

## 3. Gates (D2, pre-registered)

The gates are evaluated on the **final tier**; dev-tier values are reported next to them. All metrics come from `utils.v2_metrics.evaluate`.

| Gate | When / candidate | Criterion | Definition |
|---|---|---|---|
| **G-A** | End of Phase A; stage-2 last iterate | `eta_T_over_dw ≤ 0.005` | η₂/ΔW = max over the full final-tier D₂ grid of the one-step deviation gap Δ₂(d), /ΔW (`verify` → `full_delta_max[2]`) |
| | | `stage2_rmse_pos_over_g2_0 ≤ 0.05` | RMSE of ê₂ − e₂* over the recovery-grid nodes with \|d\| < 2q, /e₂*(0) (`recovery_metrics`; tier-independent) |
| | | `stage2_tail_mean_over_g2_0 ≤ 0.02` | mean of ê₂ over recovery-grid nodes with \|d\| ≥ 2q, /e₂*(0) (`recovery_metrics`; tier-independent) |
| **G-F** | End of Phase B; full last iterate (live t=1, frozen t=2) | `Gmax_full_over_dw ≤ 0.01` | max over t and the final-tier grid of G_t(d) = V_t^BR(d) − V_t^mean(d), /ΔW |
| | | `stage1_rel_err_abs ≤ 0.10` | \|ê₁(0) − e₁*(0)\|/e₁*(0) |

**Run outcome.** A run passes if and only if it passes G-A and G-F.
- A run that fails G-A is a **stage-2 failure**. Its Phase B is still executed and reported as a diagnostic, and the run counts as failed.

**Reported, not gated.**
- Stage 2: signed and location-free peak error at d = 0, symmetry error, tail max, Δ₂ on-path and off-path max, σ₂(0), and the smoothed-game noise share at d = 0 (Pilot-1 method, 400 equal-probability nodes per Beta).
- Stage 1 and full policy: EXP_root, dReach, Δmax_all, dFull, the stage-1 decomposition (learning and inherited terms with residual bands; final tier; step 0.01; floor = max(Δ₁(e₁*; e₂*), 1e−12·ΔW); sweep anchored at e₁* covering [min(0.4e₁*, ê₁ − 2), max(1.7e₁*, ê₁ + 2)]), and σ₁(0).
- Numerics: dev-tier minus final-tier difference of every gate and reported metric. RMSE and tail are tier-independent by construction, so their difference is 0.

**Peak error (D4).** Not gated. It is reported with its decomposition: the smoothed-game share, and the representation floor from `reports/v2/pilot4_stabilization.md` §1d.
