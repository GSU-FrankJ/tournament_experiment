## 1. Gates (primary; decide the run)

All values are on the **final tier** unless stated otherwise. Every "≤" is **inclusive**, compared at full float64 precision with no rounding. Metrics come from `utils.v2_metrics.evaluate`.

| Gate | When / candidate | Criterion | Definition |
|---|---|---|---|
| **G-A** (unchanged) | End of Phase A; stage-2 last iterate | `eta_T_over_dw ≤ 0.005` | max over the full final-tier D₂ grid of Δ₂(d), /ΔW |
| | | `stage2_rmse_pos_over_g2_0 ≤ 0.05` | RMSE of ê₂ − e₂* over recovery-grid nodes with \|d\| < 2q, /e₂*(0) |
| | | `stage2_tail_mean_over_g2_0 ≤ 0.02` | mean of ê₂ over recovery-grid nodes with \|d\| ≥ 2q, /e₂*(0) |
| **G-F** (v1.1) | End of Phase B; full last iterate (live t=1, frozen t=2) | `Gmax_full_over_dw ≤ 0.01` | max over t and the final-tier grid of V_t^BR − V_t^mean, /ΔW |
| **G-N** (new) | η₂ at the end of A; Ĝmax at the end of B | \|η₂(dev) − η₂(final)\|/ΔW ≤ 0.001 | the G-A η₂, development vs final tier |
| | | \|Ĝmax_full(dev) − Ĝmax_full(final)\|/ΔW ≤ 0.001 | the G-F Ĝmax, development vs final tier |

**Run pass** = G-A ∧ G-F ∧ G-N. In addition, a run with a global-RNG violation (§4) or any other nonzero exit counts as failed.
- A G-A failure is recorded as a **stage-2 failure**. That run's Phase B still runs and is reported, and the run counts as failed.

## 2. Secondary criterion S1 (pre-registered; not part of run pass)

- **S1:** |ê₁(0) − e₁*(0)|/e₁*(0) ≤ 0.10.
- **Per run:** the value, and pass or fail.
- **Per q:**
  - the S1 pass count, with an exact Clopper–Pearson 95% CI;
  - the mean signed stage-1 relative error, with a 95% percentile bootstrap CI (10,000 resamples; seed **20261002**; a fresh `numpy.random.default_rng(20261002)` for each q, q ascending);
  - the median and the SD (ddof = 1).
- S1 has **no pass rule**.
- The **v1.0 outcome** (G-A ∧ v1.0 G-F, where v1.0 G-F = Ĝmax_full/ΔW ≤ 0.01 ∧ S1) is reported for every run and decides nothing.

## 3. Pass rule and confirmation design

- q ∈ {50, 60}.
- Seed block **20501–20520**, confirmed by the owner; the same 20 seeds are used for both q (40 runs).
- **Pass rule:** for each q, at least **18 of 20** runs pass (§1). The confirmation passes if and only if both q pass. Each q's pass rate is reported with an exact Clopper–Pearson 95% CI.
- **Crashes:**
  - Infrastructure kill (out of memory, disk full, process killed): move the run directory to `confirmation/crashed/q{q}/seed{s}_attempt1/` and re-run once into the original path. If the re-run also fails for an infrastructure reason, the round stops and that run is not counted either way.
  - Any other nonzero exit (a pipeline exception, or a global-RNG violation) counts as a failed run.
- Every run is reported, failures included. Nothing changes after the lock.

## 4. Hardening of the process-global RNGs

The three process-global RNGs are torch global, numpy legacy global and Python `random`.

- **Seeding.** At the start of `run_v2_T2_locked.run_pipeline` (the function the in-process smoke test also calls), before any object is constructed: `torch.manual_seed(seed)`, `np.random.seed(seed)`, `random.seed(seed)`, with the run seed. The seeds are recorded in the manifest.
- **Reference state.** Each RNG's state immediately before the first Phase A update, taken by `Run.phase_start_hook` at the entry of Phase A, after the phase-entry snapshot refresh. The post-seed state and the state after `Run` construction are also recorded, so draws between seeding and the reference are visible.
  - Known draw: PyTorch's default `nn.Linear` initializer draws from the torch global RNG while `BetaActor` and `Critic` are constructed. Their weights are then re-initialized from the explicit torch generator. Source: `tools/v2/global_rng_trace.py` → `results/v2_T2_locked/v1_1/global_rng_trace.json`.
- **Assertion.** Each state must equal its reference at the end of A, after G-A, at the end of B, and at the end of the run.
  - On a violation, the RNG and the point are recorded in `gates.json`. The run finishes and writes all outputs, the entry point exits with code **5**, and the run counts as failed.
- **Digests.** The manifest records the SHA-256 of each RNG state at seeding, after `Run` construction, at the reference point, at the start of Phase B, and at each assertion point.
- **Training is unchanged.** The re-rehearsal check R1 verifies this.

## 5. Training-relevant state (every bit-identity check)

**Compared:**
- actor, critic, lagged opponent, frozen stage-2 snapshot (Phase B), and both Adam states;
- the five training RNG streams (env, learn, opp, start, minibatch) and the torch generator;
- all weight exports and the final weights;
- training histories and per-update logs, without their wall-clock fields;
- checkpoint metrics, gate-metric values, and the evaluation outputs (`gateA_*.npz`, `final_*.npz`, `induced_band.json`, `band_sweep.npz`, `drift_test.json`).

**Excluded:** verdict fields, manifests, and the three process-global RNG states.

## 6. Change log, v1.0 → v1.1

**The PI decided every change after the development-seed rehearsal (v1.0) and before any confirmation seed was run.**

1. **The stage-1 criterion moves from G-F to S1.**
   - Evidence: `reports/v2/protocol_lock_and_rehearsal.md` §4.3–§4.5; `results/v2_T2_locked/rehearsal_analysis/gates_per_run.csv`.
   - All 3 v1.0 rehearsal failures were on the stage-1 criterion (0.103, 0.126, 0.113). Their Ĝmax_full/ΔW was 0.0021–0.0023, at (t = 1, d = 0). G-A passed 20/20.
   - Signed stage-1 error SD (ddof = 1): 0.0515 (q=50) and 0.0698 (q=60). 90th percentile of |error|: 0.0889 and 0.1143.
   - The 0.10 threshold was set from the Pilot 4 distributions, whose Phase B parents had a constant-LR Phase A; the locked pipeline's distribution has a heavier upper tail.
   - **v1.0 confirmation pass probability, recomputed** (`tools/v2/v1_0_pass_probability.py` → `results/v2_T2_locked/v1_1/v1_0_pass_probability.json`):

     | Model | Recomputed | PI-side |
     |---|---|---|
     | Rate model (true rates 9/10, 8/10) | **0.1395** | ≈ 0.14 |
     | Normal model, fitted mean −0.0135 / −0.0021, SD (ddof = 1) 0.0515 / 0.0698 | **0.3494** | ≈ 0.35 |
     | Normal model, with the PI's rounded inputs | 0.3388 | |
     | Normal model, SD ddof = 0 | 0.4673 | |

     These agree with the PI-side values when the sample SD (ddof = 1) is used. The normal model treats G-A and the Ĝmax criterion as always passing, as they did in all 20 rehearsal runs.
2. **G-N is added.**
   - Evidence: `reports/v2/protocol_lock_and_rehearsal.md` §4.5; `results/v2_T2_locked/rehearsal_analysis/gate_distributions.csv`.
   - In the v1.0 rehearsal the dev − final differences of η₂ and Ĝmax_full were at most 2.2e−4·ΔW.
3. **Hardening of the process-global RNGs (§4).**
   - Motivated by rehearsal Check 1 (`reports/v2/protocol_lock_and_rehearsal.md` §4.1 and addendum): three unseeded, never-consumed process-global RNG states differed between processes.
4. **Bookkeeping that follows from D1 and D4:**
   - the training-relevant state definition (§5);
   - the confirmed seed block;
   - exact Clopper–Pearson CIs;
   - the v1.0 outcome reported only;
   - the crash rule;
   - the pre-registered analysis script.
