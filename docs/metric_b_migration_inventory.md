# Metric B Migration Inventory

Goal: switch all "final effort" and "gap" reporting from Metric A (sample mean = `(agent1_effort + agent2_effort) / 2`) and Metric C (last-N averaging) to Metric B (`policy_mean_effort[-1]`, deterministic policy distribution mean).

## Root cause

`paper/generator/extract.py` defines `effort_mean = (agent1_effort + agent2_effort) / 2` at data-load time. All downstream code (metrics, tables, plots) uses this `effort_mean` column for gap/error computations. This is Metric A — the sample-based average — not the deterministic policy mean from the JSON's `policy_mean_effort` field.

Additionally, in the nested-format loader (line 218), the code sets `policy_mean_effort = effort_mean`, clobbering the real JSON field with the sample average.
