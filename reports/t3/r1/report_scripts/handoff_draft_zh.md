# T3-R1 交接说明

日期：2026-10-17。分支 `t3-r1`。本文只写结果和去哪里看；所有数字都可以在下面链接的报告和 `results/t3_r1/` 的表里核对。本文不做任何决定，也没有发给任何人。

## 一句话结论

在预先登记的设计下（每个 q 取 20 个种子，各方案按策略样本行数对齐预算），T = 3 时逆向归纳（`bw`）的全域偏离收益 `Gmax_full/ΔW` 明显小于从根节点联合训练（`jt`）和带探索起点的联合训练（`jt_es`）；T = 2 时已记录的 v2.0 逆向归纳同样优于联合训练 `jt2`。四个预先登记的假设（H1、H2、H3、H1-T2）在 q = 50 和 q = 60 上都成立（判据：配对差均值的 95% 自助区间上端在两个 q 上都小于 0）。

## 做了什么

- 160 次新运行（`bw`、`jt`、`jt_es` 各 40 次，T = 3，种子 50501–50520；`jt2` 40 次，T = 2，种子 30501–30520），一次启动，全部正常退出；14 项启动后检查在 160 次运行中全部通过。
- 与 40 次已记录的 v2.0 确认运行（`v20`）重新评估后的结果配对比较（评估器与记录逐位一致）；这一块不对 v2.0 提供任何新的确认。
- 判据和预测在启动前已写入并推送（`02_preregistration.md`）；分析结果由独立程序重算，差异小于 1.2e-16；报告中的数字另经独立事实核查（两轮，台账在 `pi_record/01_factcheck.md`）。

## 主要数字（`Gmax_full/ΔW` 的配对差均值，括号为 95% 区间；q = 50，q = 60）

- H1（`bw` − `jt`）：−0.18054 [−0.23237, −0.13464]，−0.10019 [−0.12522, −0.07612]。
- H2（`bw` − `jt_es`）：−0.01115 [−0.01306, −0.00937]，−0.00896 [−0.01317, −0.00252]。三者中差最小、区间最接近 0 的一个。
- H3（`jt_es` − `jt`）：−0.16939 [−0.22104, −0.12330]，−0.09122 [−0.11459, −0.06952]。
- H1-T2（`v20` − `jt2`）：−0.00923 [−0.01054, −0.00808]，−0.01248 [−0.01442, −0.01088]。
- 均值：`bw` 0.00249 / 0.00476，`jt_es` 0.01365 / 0.01373，`jt` 0.18303 / 0.10495；`v20` 0.00188 / 0.00113，`jt2` 0.01111 / 0.01361。

## `bw` 在 T = 3 的表现

`bw` 同时通过 G-A、G-F、G-N 三个门的运行数是 q = 50 时 18/20、q = 60 时 18/20，正好达到预先登记的读法（两个 q 都至少 18/20），没有余量；按该读法，v2.0 的设计是 T = 3 锁定的候选。四次失败：q = 50 的两次（种子 50504、50517）是 G-A 中第三阶段的 η₃ 略超 0.005（0.00623、0.00568）；q = 60 的两次（种子 50514、50517）是 G-F，在第二阶段、带内：0.05628（约为门限的 5.6 倍）和 0.01089。`jt` 在两个 q 上都没有任何一次通过 G-A 或 G-F；`jt_es` 通过 G-F 的是 4/20（两个 q），G-A 为 0。本轮没有检验这些失败的原因，也没有尝试补救。

## 增益在哪里

`jt` 的最大增益在 40 次运行中全部出现在带外（第二阶段，域边缘），`jt2` 为 40 次中的 34 次；`jt_es` 的最大增益 40 次中有 33 次在带内；`bw` 全部在带内。根路径上的增益（EXP_root）对各方案的排序与 `Gmax_full` 一致，但差距小得多（`bw` − `jt` 的差在 EXP_root 上比在 `Gmax_full` 上小约 20 倍和 11 倍），所以只看根路径会低估联合训练的问题。各方案带外增益的大小与它们对带外区间的访问次数的顺序一致，但这只是观察到的共变，本轮没有覆盖度对齐的对照，不能据此断言原因。

## 预测（D8）对照

P1：H1 与 H1-T2 成立，`jt` 与 `jt2` 的最大增益多在带外，`jt_es` 不是。P2、P3 成立。P4 的前半句成立（18 对 19、20），后半句只在 q = 50 成立（q = 60 的两次失败是 G-F，不是 G-A）。

## 没有解决的问题

容量（`bw` 三个网络，联合训练一个网络）、与 `bw` 覆盖度对齐的联合训练、其他预算（按更新数、按步数或墙钟时间对齐）、四次 `bw` 失败的原因、以及更多种子。下一轮怎么做由 PI 与合作者决定；`06_decision_inputs.md` 列出了读法、各假设的适用范围和未经检验的选项，但不做决定。
