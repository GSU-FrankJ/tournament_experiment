# T3-R2 交接说明（给合作者）

本轮做了两件事：先审计 T3-R1 里 `bw` 的四个失败，看有没有实现错误；确认没有之后，把 `bw` 的设置原样锁定，在 20 个全新的种子上重新训练并检验。结论先说：**审计没有发现实现错误；确认没有通过预先写好的规则。**

## 1. 审计（有没有实现错误）

没有发现。具体证据（全部来自已有记录和重新计算，没有新跑种子，只重跑了四个失败的 run）：

- 四个失败的 `bw` run 从各自原来的 `run_config.json` 重新训练，结果与原来逐位一致（162 个 npz 文件、除墙钟时间列之外的全部 CSV、最终状态，以及评估表的 137 列）。
- 40 个 `bw` run 里，被评估的三个快照（第 3 阶段冻结、第 2 阶段冻结、第 1 阶段在线网络）与对应的权重导出文件逐位相同；8 个 run 的两张延续价值表用代码重建后逐位相同。
- 第 2、第 3 阶段的训练语义（观测编码、角色符号、延续表的取值、滞后对手、第 3 阶段奖励）用单元测试逐项检查（预期值手算，或用相同随机数重放），全部通过。
- 另写了一个完全独立的最优反应计算器（不使用验证器和指标模块的任何数值程序）。对 200 个 run（T3-R1 的 160 个加上 T = 2 的 40 个 v2.0 run）重新算增益：与验证器存下的值相差最多 2.5e-5 ΔW（G）、5.5e-6 ΔW（Δ_T）、1.0e-4 ΔW（EXP_root），都远小于 G-N 的容差 0.001 ΔW；没有任何一个 run 的门禁判定翻转，H1、H2、H3、H1-T2 的结论也没有变化。更细的验证器网格（refined tier）同样不改变任何判定。
- 第 2 阶段"近零努力段"（七个 run，共 126 个节点，其中包括两个 q = 60 的失败）是学习失败，不是博弈本身的性质：每个节点上单步最优反应都大于 1，目标函数在已学到的努力值处是上升的，在零附近没有局部极大。七个里有六个在第 2 阶段第一次导出时就已经低于 1；只有 q = 60 的 seed 50514 是在训练中途（更新 2475 到 2750 之间）形成的。这些节点并不都一直停在低位：seed 50517（q = 60）的段中途部分恢复（失败节点的努力约 9 到 16），到更新 2950 到 3200 又塌回去。

## 2. 确认（新种子，预先写好的规则）

锁定的设置就是 T3-R1 的 `bw`，一个字没改。种子 60501–60520，q = 50 和 q = 60 各 20 个，共 40 个 run。规则事先固定：总共至少 36 个通过，并且每个 q 至少 17 个通过。

- 40 个 run 全部正常结束，没有基础设施故障，所有事后检查（配置、预算、学习率、快照、导出、C-INIT、C-REPLAY）全部通过（检查程序第一次用了相对路径的 `--root`，其中一项配置对比因程序对相对路径的处理缺陷而显示 0/40；我手工核对了 40 个配置的哈希与计划一致，换绝对路径重跑同一程序后全部通过，详见 03_checks）。
- **结果：40 个里 34 个通过（q = 50：16/20；q = 60：18/20），规则未满足**（总数 34 < 36，q = 50 的 16 < 17；q = 60 满足）。精确 95% 区间：q = 50 为 [0.563, 0.943]，q = 60 为 [0.683, 0.988]，合计 [0.702, 0.943]。独立重算的程序给出相同结果。
- 六个失败**全部发生在第 3 阶段**：q = 50 的 60501、60506、60513 只是 η_3 略超 0.005（超出 0.0002 到 0.0022），60515 的 η_3 和 Gmax_full 为 0.0114 且 RMSE 为 0.0667；q = 60 的 60516 只有形状误差 RMSE 略超限（0.0538 对 0.05），60518 是一个始终没有形成的第 3 阶段策略（e_3(0) 只有 8.2，理论值 58.3；Gmax_full = 0.145，是两轮共 80 个 `bw` run 里最大的）。没有任何失败的失败量位于第 2 阶段；近零段只在三个 q = 50 的 run 出现（其中 60506 和 60515 也在六个失败之列，但它们失败的是第 3 阶段的量），位于带宽边缘，且都很短。
- 描述性对比：与 T3-R1 的 36/40 合并是 70/80（区间 [0.782, 0.938]）。中位数接近，尾部更差；q = 50 有 17/20 个 run 在最后 16 次导出中至少一次 η_3 超过 0.005（T3-R1 为 14/20）。

## 3. 没有做的事

按规定，确认失败后本轮不调参、不再跑第二批、不试别的方案。第 3 阶段失败的机制没有检验；第 2 阶段近零段为什么训练出不来，也只做了描述。下一步由 PI 决定。
